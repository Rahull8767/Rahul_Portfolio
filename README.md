# Rahul Tembhare | Video Editor & Visual Artist

A modern, high-performance portfolio showcasing cinematic edits, motion graphics, color grading, and VFX. Built with React, TypeScript, and Vite.

**[🌐 View Live Portfolio](https://rahull8767.github.io/Rahul_Portfolio/)**

---

## ✨ Features

- **Immersive Video Experience**: Custom-built video modal that integrates with the browser's history state (supports mobile back button navigation seamlessly).
- **Smooth Animations**: Powered by Framer Motion, featuring dynamic scroll-triggered reveals, continuous infinite-scroll carousels, and an interactive mouse spotlight.
- **Optimized Video Delivery**: Video assets hosted and streamed efficiently via Cloudinary.
- **Fully Responsive**: Carefully crafted to look perfect on desktops, tablets, and mobile devices.
- **Dark Mode Aesthetic**: A sleek, minimal, premium dark theme with vibrant purple and pink gradients.

## 🛠️ Tech Stack

- **Framework**: [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Routing**: [Wouter](https://github.com/molefrog/wouter)
- **Deployment**: GitHub Pages (via GitHub Actions)

## 🚀 Local Development

The main portfolio application is located inside the `artifacts/rahul-portfolio/editing/` directory.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) and [pnpm](https://pnpm.io/) installed.

### Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/Rahull8767/Rahul_Portfolio.git
   cd Rahul_Portfolio
   ```

2. **Navigate to the application root**
   ```bash
   cd artifacts/rahul-portfolio/editing/
   ```

3. **Install dependencies**
   ```bash
   pnpm install
   ```

4. **Start the development server**
   ```bash
   pnpm run dev
   ```
   Open `http://localhost:5173` in your browser.

## 📦 Deployment

This repository is configured with a custom GitHub Actions workflow (`.github/workflows/deploy.yml`) that automatically builds and deploys the portfolio to GitHub Pages whenever changes are pushed to the `main` branch.
